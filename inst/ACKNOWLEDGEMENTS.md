## Microsoft contracts and examples

The JSON schema snapshot under `inst/schemas/` is copied from Microsoft's
[json-schemas repository](https://github.com/microsoft/json-schemas). Its
original MIT notice is preserved in `inst/schemas/LICENSE-MICROSOFT`.

`theme-schema.json` is Microsoft's published Power BI theme schema from
[powerbi-desktop-samples](https://github.com/microsoft/powerbi-desktop-samples),
also MIT-licensed. The same Microsoft notice is retained. Schema versions and
the retrieval date are documented beside the files.

Current public Power BI samples were inspected to confirm native query-role
names and formatting properties. The compiler code is an original implementation
of public contracts; sample data and proprietary PBIX binaries are not bundled.

The accessible categorical palette is based on the widely used Okabe-Ito colors.
Color choices alone do not establish accessibility conformance; use clear labels,
alt text and review the final report in its intended context.

## Tutorial data and documentation

The optional nycflights13 package is installed separately and is not vendored. The flights
tutorials use its flights, airlines and airports data and retain the dataset names and
source attribution. Flights originate from the US Bureau of Transportation Statistics;
airport metadata is attributed by nycflights13 to OpenFlights. Consult the package and
upstream data notices for the terms applicable to those datasets.

* [nycflights13 package and contributors](https://nycflights13.tidyverse.org/)
* [Flights source and variables](https://nycflights13.tidyverse.org/reference/flights.html)
* [Airport metadata source](https://nycflights13.tidyverse.org/reference/airports.html)
* [Posit Shiny reactivity documentation](https://shiny.posit.co/r/getstarted/build-an-app/reactivity-essentials/reactive-elements.html)
* [Microsoft TMDL reference](https://learn.microsoft.com/en-us/analysis-services/tmdl/tmdl-overview)

No proprietary Power BI binary, Microsoft TOM assembly, or font file is distributed.
The native acceptance helper loads an assembly explicitly supplied from a trusted
Microsoft installation.
