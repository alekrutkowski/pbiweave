# pbiweave 0.3.1: project path hotfix

## Symptom

`pbi_compile(..., bundle = TRUE)` from 0.3.0 can fail with:

```text
Error: Project path escapes the project: .gitignore
```

## Why

The 0.3.0 file-boundary helper compared a normalized file path with a
canonicalized directory path. On Windows, these may have distinct path
representations for the same location. In particular, `.gitignore` is a
legitimate dotfile generated by the package and should not be rejected.

## Resolution

Install version 0.3.1 from a new R session, then rerun the original code.
Relative path traversal and absolute paths remain prohibited. Real parent
directories are checked after resolving directory links. On Unix, symlinked
leaf entries are also rejected using `Sys.readlink()`; Windows R does not
provide an equivalent leaf-link inspection through that API.

```r
install.packages("pbiweave_0.3.1.tar.gz", repos = NULL, type = "source")
library(pbiweave)
stopifnot(as.character(packageVersion("pbiweave")) == "0.3.1")
project <- pbi_example("showcase", theme = "midnight") %>%
  pbi_compile("commercial-dashboard-v031", bundle = TRUE)
stopifnot(pbi_check(project, verify_hashes = TRUE)$valid)
pbi_open(project)
```

**First open:** select Home ➜ Refresh, then Save As `.pbix`.

This release has not been executed in native Power BI Desktop or a local R
runtime during preparation. Run its R test suite and Windows CI acceptance
before considering the fix production-certified.
