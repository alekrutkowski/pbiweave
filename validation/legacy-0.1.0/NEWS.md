# pbiweave 0.1.0

- Declarative dashboards, copied data snapshots, DAX measures, explicit calendars,
  many-to-one relationships and typed filters.
- Fifteen native visual families, multiple-value charts, card collections,
  synchronized slicers and native/filter/disabled page interactions.
- Six themes, per-page backgrounds, four layout families, grid spans, exact
  positions, custom canvas sizes, titles and accessibility descriptions.
- Portable enhanced PBIR reports and typed TMSL Import models with compressed
  embedded data, deterministic identifiers and source-file checksums.
- Transactional compilation, ZIP bundles and explicit Desktop finishing steps.
- Semantic preflight checks, exact Int64/fixed-decimal handling, runtime tests,
  offline Microsoft schema validation and Windows/Linux CI configuration.
- Sixteen worked examples, including a multipage executive showcase.
